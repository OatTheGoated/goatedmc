💡 How to Use Schematics

  1. Download the .schematic file
  2. Install WorldEdit mod (if not already installed)
  3. Place the file in your .minecraft/schematics folder
  4. In-game, use: //schem load filename
  5. Position your cursor and use: //schem paste
